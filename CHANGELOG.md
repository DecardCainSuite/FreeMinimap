## Free Minimap 1.7.0

- **Free positioning** without the Edit Mode: choose “Placed by” Free Minimap or Edit Mode, set X / Y, or unlock and drag the map.
- The position is kept safe in combat (unlock is refused, the map locks itself and the position is applied after combat).
- From 1.6.0: every element around the map (zone, coordinates, clock, tracking, calendar, day/night, mail, difficulty, addon compartment, zoom) can be placed, scaled and shown always, on hover or never.
- From 1.6.0: no more “blocked action” errors on the minimap in combat.
- On a fresh install the shipped size (374 × 175) is now used instead of 192 × 192.
- Built for WoW Forever only: the unused Classic code and old settings were removed.
